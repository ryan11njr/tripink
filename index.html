不是又一份 AI 文字攻略。TripInk 读懂你 → 查证世界，把你的行程印成一本可交互的旅行杂志——海拔剖面、真实导航路线、实时天气、导游级讲解、预算仪表盘，全部装进一个双击就开的网页。

Pillars

它不一样在哪

最懂你

先读懂这趟旅行：谁同行、什么纪念日、什么节奏。隐性需求探测 + 每轮主动推荐（隐藏玩法 / 省钱点 / 风险预警 / 仪式感彩蛋），不等问、先想到。

最靠谱

门票与预约规则、天气、油价、经验帖，联网查证、多源交叉，每个数字带来源与日期；网页在旅途中持续拉取当天的真实天气与导航路线；查不到就标"未核实"。

随身行

输出 HTML（按旅行风格定制审美）· PDF · Word · MD。HTML 单文件双击即开，一路出行随时查。

Install

安装（选你的智能体）

Claude Code

复制到个人技能目录后，说"帮我规划一次旅行"即触发。

git clone https://github.com/ryan11njr/tripink.git
# Windows
xcopy /E /I tripink\skill\travel-planner "%USERPROFILE%\.claude\skills\travel-planner"
# macOS / Linux
cp -r tripink/skill/travel-planner ~/.claude/skills/

Codex

放入 Codex 技能目录（SKILL.md 约定），对话中同样触发。

git clone https://github.com/ryan11njr/tripink.git
cp -r tripink/skill/travel-planner ~/.codex/skills/

其他智能体

任何支持 SKILL.md 约定的智能体：把 skill/travel-planner 放入其技能目录，或在 AGENTS.md / 系统提示中引用该 SKILL.md 的路径。

路径：skill/travel-planner/SKILL.md
依赖：联网搜索 + 网页读取工具即可（无其它依赖）

Story

为什么叫 TripInk

古人出嘉峪关，要领一份"关照"——它既是通行凭证，也意味着一路有人照应。TripInk 想做一份属于今天的"关照"：先读懂谁要出发、为何出发，再查证门票、天气与路线，把结果印（ink）成一本可以点开的旅行杂志。它不替你旅行，只让每一步更明白，也更像你。
