让 AI 写攻略不稀奇，稀奇的是写完真的能用。
TripInk 会先问清楚你的同行人、节奏和预算习惯，再去查证门票、天气、油价和真实经验，
最后把整趟行程做成一个能点开的网页——出发前是攻略，在路上是手册。

01

五步，从一句话到可直接使用的靠谱路书

装好之后，剩下的就是聊天。

1装技能复制进技能目录
2说一句话"帮我规划一次旅行"
3答问卷人数 · 天数 · 风格 · 预算
4看它查证门票 · 天气 · 油价 · 经验帖
5拿成品网页 + PDF / Word / MD
02

它有什么不一样

三个实在的差别。

Knows you

最懂你

带爸妈同行，节奏自动放慢；赶上纪念日，行程里会留出一段仪式感。你不必逐条交代，它会先替你想到——包括"这张票要提前七天预约"这样的坑。

Verified

最靠谱

门票价格、开放时间、当天天气、一路油费，全部当场查证，标注来源与日期；查不到的，老实写"未核实"。出发那天，网页里的天气和路线依然是新的。

On the road

随身行

成品是一个双击即开的网页，手机同样能看；需要存档，随时导出 PDF、Word 或 MD。

05

怎么装

一套 SKILL.md，三个平台通用。

复制到个人技能目录，然后说一句"帮我规划一次旅行"即可。

git clone https://github.com/ryan11njr/tripink.git
# Windows
xcopy /E /I tripink\skill\travel-planner "%USERPROFILE%\.claude\skills\travel-planner"
# macOS / Linux
cp -r tripink/skill/travel-planner ~/.claude/skills/

放入 Codex 技能目录（SKILL.md 约定），对话中同样触发。

git clone https://github.com/ryan11njr/tripink.git
cp -r tripink/skill/travel-planner ~/.codex/skills/

任何支持 SKILL.md 约定的智能体：把 skill/travel-planner 放入其技能目录，或在 AGENTS.md / 系统提示中引用该 SKILL.md 的路径。

技能入口：skill/travel-planner/SKILL.md
依赖：联网搜索 + 网页读取工具即可（无其它依赖）
06

里面都有什么

SKILL.md全流程：问卷 · 隐性需求探测 · 五源交叉验证 · 主动推荐引擎 · 主题×模式 · 构建 QA · 发布
themes.md六套配色主题 tokens
zine-modes.md四种展示模式与 CSS 配方
data-schema.mdELEV / DAYS / TIPS / GSRC / GIMG / CATS 数据规范
template.html完整可运行网页模板（即本站 Demo）
optimize_images.py配图压缩工具
Why the name 古时候出嘉峪关，得先领一份"关照"——相当于古代的护照，意思是这一路有人照应。TripInk 想干的就是这件事：出发前把你没想到的替你想到，把查得到的都查清楚，再把你的行程"印"成一本能点开的杂志。
