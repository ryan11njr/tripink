# TripInk 爆款传播方案（Promotion Playbook）

> 定位一句话：**不是又一份 AI 文字攻略，而是"把行程印成可交互旅行杂志"的开源技能**——海拔剖面、真实导航路线、按到达日实时天气、导游级讲解、预算仪表盘，全部装进一个双击就开的网页，另有 PDF / Word / MD 存档。
> Slogan：**Your trip, in ink. / 最懂你的旅行设计师。**
> 三大支柱（一切内容围绕它们）：**最懂你**（隐性需求探测+主动推荐）· **最靠谱**（数据实时、来源可查、出发时仍是新的）· **随身行**（风格化 HTML 实时随行 + 多格式存档）。

---

## 0 · 传播素材前置清单（发布前必须备齐）
1. **15 秒 GIF**（README 首屏）：首页海拔剖面 → 点进莫高窟讲解卡展开 → 预算仪表盘。ScreenToGif 录制，480px 宽 <8MB。
2. **左右对比图**（封面主力）：左"手机备忘录烂攻略" vs 右"TripInk 生成的杂志网页"。
3. **OG 分享图** 1200×630（Logo 文档已给 prompt）。
4. 在线 Demo 短链 + 二维码：`ryan11njr.github.io/tripink/`。
5. 3 张"景点讲解卡"截图（莫高窟典故卡最抓人）+ 1 张天气卡截图（打"实时"心智）。

## 1 · 抖音打法（3 条种子视频 + 可复制框架）

**黄金 3 秒钩子库**：
- "我把 AI 做的旅行攻略发给了同行朋友，她以为是我花 500 块买的。"
- "别再让 AI 吐一坨文字攻略了——看这个。"
- "爸妈金婚 40 年，我给他们做了个旅行网站当礼物。"（情感向，最易爆）
- "和 AI 聊了 10 分钟，它把我的西北行做成了一本杂志。"
- "这个攻略里的天气，是我到那天才生成的。"

**视频 A · 变身式（冷启动主力）**：3 秒对比图开场 → 屏录快剪"我只回答了 7 个问题" → 成品滚动展示（卡点 BGM）→ 落版 "TripInk · Your trip, in ink. 开源，主页自取"。30–40 秒。
**视频 B · 过程式（信任向，打'最靠谱'）**：全程屏录，重点剪 AI 查门票/天气/小红书的瞬间（字幕放大"它在帮我查莫高窟还有没有票"），成品 5 秒收尾。60 秒。
**视频 C · 情感式（破圈向，打'最懂你'）**：金婚/带爸妈/毕业旅行故事线——"它还提醒我那天是爸妈的纪念日"，网站成品当"礼物"揭晓。
**框架规则**：每条只打一个支柱；7 秒内必出成品画面；评论区置顶 Demo 链接 + 获取方式。
**节奏**：周 3 条 × 2 周，卡出行高峰前 7–10 天；爆了立刻追"怎么做"教程承接。
**标签组**：#AI #旅行攻略 #Claude #开源项目 #旅行规划 #自驾游 + 目的地词。

## 2 · 小红书打法（图文为主）

**封面 AB 测**：
- A 大字对比：左"我的 Excel 行程"右"AI 做的杂志"，红字"差距有多大？"
- B 成品九宫格 + 角标"3 人 8 天 · 人均 3539 · 数据全实时"（对号入座式细节上封面）。
**标题公式**（≤20 字，数字+反差+结果）：
- "和 AI 聊了 10 分钟，它把我的西北行印成了杂志"
- "免费开源！这个 Claude 技能把攻略做成了网站"
- "带爸妈旅行前，我用 AI 做了这个…"
**正文结构**：痛点（攻略=一坨文字）→ 过程 3 步图 → 成品细节 3 图（讲解卡/实时天气/预算）→ "怎么获得"3 行教程 → 提问结尾（"下一站想去哪？评论区扔给我试"）。
**评论区运营**：置顶 Demo + "想要同款扣 1"；每 50 个"扣 1"发一篇进阶教程；所有求教程的引导到 GitHub。
**合集化**："AI 旅行实验室"合集，每条新行程（新疆/川西/云南）都是一篇，形成追更。

## 3 · GitHub / 开发者圈打法

1. **README = 落地页**：首屏 15s GIF + "Your trip, in ink." + 在线 Demo 大按钮；第二屏讲三大支柱；**用一个真实故事开场**（比如：出发去敦煌前，AI 提醒我"出嘉峪关，古时候要领一份'关照'"——这段讲解就在它生成的网页里）。
2. 双语 README；badges；"10 行安装"置前；用户行程展示墙（链接到大家的 Pages，互推）。
3. **投稿矩阵**（star 主引擎）：GitHubDaily、HelloGitHub、awesome-claude-code / awesome-claude-skills / awesome-agents 提 PR；V2EX 分享创造、少数派、linux.do、即刻。
4. Release 节奏：v1.0 → 3 天内 v1.1（吸收 issue）→ 每个新目的地 demo 一次小版本。
5. Discussions + 微信群；"晒出你的 TripInk 行程"置顶帖（UGC 反哺素材）。

## 4 · 冷启动 72 小时清单
- **D0 晚**：GitHub v1.0 + Demo 自测；小红书图文①；抖音视频 A。
- **D1**：投稿 GitHubDaily/HelloGitHub/awesome×3；V2EX；朋友圈求体验反馈。
- **D2**：抖音视频 B；小红书图文②（教程向）；回复所有评论（前 48h 互动权重最高）。
- **D3**：数据复盘（哪条钩子 CTR 高→同款加倍）；发 v1.1。
- 指标线：抖音完播 >30%、小红书点击 >8% 即加投；star 目标 首周 100 / 首月 1000。

## 5 · 长效内容飞轮
每趟新旅程 = 全渠道一次内容（视频+图文+新 demo 页+新 release）；用户用 #TripInk 之旅 发小红书并 @官号，精选上 README 展示墙。**产品、demo、内容三位一体——demo 本身就是最好的广告。**
