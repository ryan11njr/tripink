# 「关照」爆款传播方案（Promotion Playbook）

> 定位一句话：**不是又一份 AI 文字攻略，而是"把行程变成可交互旅行杂志"的开源技能**——海拔剖面、真实导航路线、按到达日实时天气、导游级讲解、预算仪表盘，全部装进一个双击就开的网页。
> 差异化壁垒：市面 AI 攻略=一屏文字；关照=**一件值得收藏、能发朋友圈的成品**。传播核心永远打这一个对比。

---

## 0 · 传播素材前置清单（发布前必须备齐）
1. **15 秒 GIF**（README 首屏）：滚动展示 首页海拔剖面 → 点进 D6 莫高窟讲解卡展开 → 预算仪表盘。可用脚本录屏（ScreenToGif），480px 宽 <8MB。
2. **左右对比图**（封面主力）：左"手机备忘录里的烂攻略" vs 右"关照生成的杂志网页"，同一次旅行。
3. **OG 分享图** 1200×630（Logo 方案 D）。
4. 在线 Demo 短链 + 二维码（现有 `ryan11njr.github.io/...`，命名定稿后换 `guanzhao`）。
5. 3 张"景点讲解卡"截图（莫高窟典故卡最抓人）。

## 1 · 抖音打法（视频 3 条种子 + 可复制框架）

**黄金 3 秒钩子库**（每条视频开头必用其一）：
- "我把 AI 做的旅行攻略，发给了同行的朋友，她以为我花了 500 块买的。"
- "别再让 AI 给你一大段文字攻略了——看这个。"
- "爸妈金婚 40 年，我给他们做了个旅行网站当礼物。"（情感向，最易爆）
- "和 AI 聊了 10 分钟，它把我的西北行做成了一本杂志。"

**种子视频 A · 变身式（冷启动主力）**：3 秒对比图开场 → 屏录快剪"我只回答了 7 个问题"（问卷界面）→ 成品滚动展示（配卡点 BGM）→ 落版"技能开源，主页自取"。30–40 秒。
**种子视频 B · 过程式（信任向）**：全程屏录对话，重点剪 AI 查门票/天气/小红书的瞬间（字幕放大"它在帮我查莫高窟还有没有票"），成品 5 秒收尾。60 秒。
**种子视频 C · 情感式（破圈向）**：金婚/带爸妈/毕业旅行故事线，网站成品当"礼物"揭晓，结尾"出发前，先领一份关照"。
**框架规则**：每条只讲一个点（要么美、要么省心、要么情感）；字幕大字关键词；7 秒内必须出现成品画面；评论区置顶"Demo 链接 + 技能获取方式"。
**节奏**：周 3 条 × 2 周，卡节假日出行高峰前 7–10 天发布；爆了立刻追"怎么做"教程视频承接流量。
**标签组**：#AI #旅行攻略 #Claude #开源项目 #旅行规划 #自驾游 + 目的地词（#大西北 #青甘大环线）。

## 2 · 小红书打法（图文为主）

**封面 AB 测**：
- A 大字对比封面：左"我做的 Excel 行程"右"AI 做的杂志"，红色大字"差距有多大？"
- B 成品九宫格：网页截图拼贴 + 角标"3 人 8 天 · 人均 3539 · 全程真实数据"（**对号入座式细节上封面**，完播/点击双高套路）。
**标题公式**（≤20 字，数字+反差+结果）：
- "和 AI 聊了 10 分钟，它把我的西北行做成了杂志"
- "免费开源！这个 Claude 技能帮你把攻略做成网站"
- "带爸妈旅行前，我用 AI 做了这个…"
**正文结构**：钩子（痛点：攻略是一坨文字）→ 过程 3 步图（问卷/它去查资料/成品）→ 成品细节 3 张图（讲解卡/实时天气/预算）→ "怎么获得"（3 行教程 + 主页/评论区）→ 提问式结尾（"你们下次想去哪，评论区扔给我试"）。
**评论区运营**：置顶放 Demo 链接 + "想要同款的扣 1"；每条求教程的回复都引导到 GitHub；每收 50 个"扣 1"发一篇进阶教程承接。
**合集化**：建"AI 旅行实验室"合集，后续每条新行程（新疆/川西/云南）都是一篇，形成追更。

## 3 · GitHub / 开发者圈打法

1. **README = 落地页**：首屏 = 15s GIF + 一行 slogan + 在线 Demo 大按钮（链接到 Pages demo）；第 2 屏才讲安装。**用嘉峪关"关照"典故开场讲故事**（demo 里现成），再讲功能——有故事的 README 转发率高 3 倍。
2. 双语 README（中文为主，English 简版链接）；badges（License/PRs welcome/Stars）；目录树清晰；"10 行安装"代码块置前。
3. **投稿矩阵**（star 主引擎）：GitHubDaily、HelloGitHub 月刊、awesome-claude-code / awesome-claude-skills / awesome-agents 各发 PR；V2EX（分享创造节点）、少数派、linux.do、即刻"一起搞AI"。
4. Release 节奏：首发 v1.0 → 3 天内 v1.1（吸收 issue，展示"活跃度"）→ 每个新目的地 demo 做一次小版本（内容即更新）。
5. 开 Discussions + 微信群（README 放群二维码，"晒出你生成的行程"置顶帖——UGC 反哺传播素材）。
6. License（MIT）+ CONTRIBUTING + "用关照做过行程的用户展示墙"（链接到大家的 Pages，互推）。

## 4 · 冷启动 72 小时清单
- D0 晚：GitHub 发 v1.0 + Demo 链接自测；小红书发图文①；抖音发视频 A。
- D1：投稿 GitHubDaily/HelloGitHub/awesome×3；V2EX 帖；朋友圈/群首发"求体验反馈"。
- D2：抖音视频 B；小红书图文②（教程向）；回复所有评论（前 48h 互动权重最高）。
- D3：数据复盘（哪条钩子 CTR 高→同款加倍）；发布 v1.1 修复反馈。
- 指标线：抖音完播 >30%、小红书点击 >8% 即加投同款；GitHub star 目标 首周 100 / 首月 1000（参照同类 skill 项目节奏）。

## 5 · 长效内容飞轮
每趟新旅程 = 一次全渠道内容（视频+图文+新 demo 页+新 release）→ 素材永远不断；鼓励用户交"行程作业"（用 #关照之旅 发小红书并 @官号，精选上 README 展示墙）→ 用户内容再引流。**产品、demo、内容三位一体，demo 本身就是最好的广告。**
