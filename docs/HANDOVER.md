## 1 · 项目全貌

**TripInk**（trip + ink）——一个开源的 Claude 技能：**读懂你 → 查证世界 → 把你的行程印成一本可交互的旅行杂志**。

三大支柱（所有文案围绕它们，不得另造卖点）：
1. **最懂你**：不做问答机。先问卷（出发地/人数/天数/交通/预算习惯/旅行风格/节奏），再做隐性需求探测（带老人→放节奏、纪念日→仪式感彩蛋……），且每轮主动推荐"隐藏玩法/省钱点/风险预警/仪式感"四件套。
2. **最靠谱**：门票与预约规则、天气、油价、小红书/马蜂窝经验帖全部联网查证、多源交叉，每个数字带来源和日期；生成的网页在旅途中持续拉取**当天真实天气与真实导航路线**。
3. **随身行**：输出 **HTML（按旅行风格定制审美）· PDF · Word · MD**；HTML 单文件双击即开，一路出行随时查（海拔剖面、导航、实时天气、预算仪表盘、导游级讲解卡）。

用户旅程五步：装技能 → 说"帮我规划旅行" → 答问卷+看它查资料 → 迭代确认 → 拿到网页/手册（可一键发布 GitHub Pages）。

**审美哲学**（写文案时可引用）：先读行程的性格，再决定呈现——六套配色主题（丝路矿物料/高原清冽/都市霓虹/海滨假日/水墨留白/山野暖木）× 四种展示模式（纸刊杂志/手账拼贴/针织暖物/极简档案），灵感致敬 GitHub 上的 zine 系作品（如 gathered-scenes-zine"先读场景再创作"）。

## 附录 A · Logo Prompt 全文（6 方向 + OG）

**通用约束（拼在每条末尾）**：
> 扁平矢量风格，2D，无渐变或仅极轻微渐变，无 3D、无投影、无描边发光；字体为现代几何无衬线（Poppins / Gilroy 气质），字距舒展、笔画干净；仅允许出现 TripInk 这一个单词（拼写精确：T-r-i-p-I-n-k，其中 T 与 I 大写），禁止任何其他文字、水印、签名、多余装饰；主体居中、大量留白；正方形 1:1；缩小到 32px 仍清晰可辨。

- **V1 墨滴点 i（主推）**：极简字标 "TripInk"，"Ink" 的 i 圆点替换为一滴下落中的朱砂红墨滴（#b23a2e，略带动势），其余字母墨黑（#1b1815），宣纸米白底（#f2e7cb），一行横排，现代而安静。
- **V2 一笔飞白下划线**：墨黑现代无衬线字标，"Ink" 下方一道手写毛笔飞白笔触下划线（一笔完成、两端出锋、笔触不均匀），朱砂红，白底。
- **V3 图标+字标**：左侧一滴朱砂红墨滴，内部负空间留出一条虚线路径、末端地图定位圆点（"一滴墨里有一条路线"）；右侧墨黑 "TripInk" 横排，垂直居中，白底。
- **V4 TI 字标 App 图标**：圆角方形图标（占画面 70%），宣纸米白底，自定义连字 "TI"——T 横笔向右延伸渐变为虚线路径，I 墨黑粗竖笔顶缀朱砂圆点；几何建筑感（此条禁止 TI 之外任何文字）。
- **V5 现代印章圆标**：细线外环（墨黑 2px），环内居中朱砂墨滴、下缘融入虚线路径与小圆点；圆环正下方小号 "TripInk"。像被现代化重绘的旅行入境章，扁平克制、无做旧。
- **V6 纯黑极简字标**（头像/水印）：纯白底仅 "TripInk"，墨黑几何无衬线 Medium，"Trip" 与 "Ink" 间留一档呼吸位，无任何图形。
- **README 横版**：在选定方向后追加一句"改为 3:1 横版，字标居左，右侧留白"。
- **OG 图（1200×630）**：左 60% 宣纸底，大号 "TripInk"（i 点为朱砂墨滴）+ 小字 "YOUR TRIP, IN INK."；右 40% 极简线稿笔记本、屏内微缩旅行网页（海拔剖面曲线+虚线路线+照片卡）；敦煌矿物料配色，杂志封面式排版；除 "TripInk / YOUR TRIP, IN INK." 外禁止其他文字。

**选稿小抄**：字标类重点看 "Ink" 的 k 收尾是否优雅；选中后迭代两轮（"字距再松 5%" / "墨滴再小一档"）；最终建议转真矢量 SVG。
