# 丝路西行 · 莘县→敦煌 自驾大环线

8 天 7 晚 · 4 人 · 中型 SUV（95 号）· 约 5,200 km 的大西北自驾路书。
南进北出大环线：莘县 → 天水（麦积山）→ 西宁 → 青海湖 → 茶卡盐湖 → 大柴旦 → 当金山 → 敦煌（莫高窟 + 鸣沙山月牙泉）→ 嘉峪关 → 张掖七彩丹霞 → 银川（西夏王陵）→ 莘县。

## 在线访问

## 互动网页包含
- 首页：**全程海拔剖面**（签名设计）+ 真实导航路线图（高德卫星底图）
- 每日分页：当日路线（OSRM 真实道路）· 行程时间轴 · **导游级景点讲解**（沿革 / 地质 / 艺文 / 看点 / 典故 + 参考文献）· **实时天气**（Open-Meteo 按到达日期）· 美食住宿 · 当日花销
- 预算仪表盘：每日花销堆叠柱图 + 类目占比

## 本地打开
双击 `index.html`（需联网加载地图瓦片、天气/导航 API；断网时天气回落到常年气候值、路线回落到直线示意）。

## 更新内容后重新发布
仓库根目录运行（Git Bash）：
```bash
bash deploy.sh
```
它会重新生成 md/pdf、复制最新文件到 `publish/` 并推送，GitHub Pages 自动更新。
